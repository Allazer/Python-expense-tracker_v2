# Python Expense Tracker

A command-line expense tracking application built using Python and SQLite.

This project is part of my practical journey towards becoming a Data Engineer and strengthening my Python programming and database management skills.

## Project Overview

The application allows users to manage personal expenses through a command-line interface. It uses SQLite for persistent data storage.

The project initially started as a JSON-based expense tracker and is being rebuilt using SQLite to gain practical experience working with relational databases and SQL.

## Technologies

- Python
- SQLite
- SQL
- Git and GitHub

## Implemented Features

- Database initialization and table creation.
- Adding expenses.
- Viewing stored expenses.
- Filtering and retrieving expense records.
- Updating existing expenses.
- Deleting expenses.
- Parameterized SQL queries.
- Input validation and reusable validation functions.
- Database connection management.

## Project Structure

- `main.py` – Application entry point.
- `database.py` – Database connection and initialization.
- `expenses.py` – Expense management and CRUD operations.
